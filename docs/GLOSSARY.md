# Brief Yourself 术语表

[中文](GLOSSARY.md) | [English](GLOSSARY.en.md) | [治理原则](GOVERNANCE.md)

| 术语 | 中文释义 | 含义 |
|---|---|---|
| Personal Context | 个人上下文 | 用户允许 Agent 在明确条件下理解和使用的个人信息与认识。 |
| Personal Context Store | 个人上下文存储 | 用户可审核的长期事实源，不等于 Agent Memory。 |
| Claim | 认识条目 / 可审核陈述 | 带来源、范围、状态、反例和敏感度的一条个人陈述。 |
| Evidence / Counterevidence | 证据 / 反例 | 支持或限制 Claim 的来源。历史首先是 Evidence。 |
| Tension / Unknown | 张力 / 未知项 | 尚不能归并的拉扯，或当前材料无法回答的问题。 |
| Core Summary | 核心摘要 | 从已确认、有效、跨场景 Claim 派生的摘要，不是第二事实源。 |
| Domain | 领域标签 | 职业、表达、协作等 Claim 标签，不是物理存储层。 |
| Context View | 上下文视图 / 冻结任务视图 | 绑定用途、执行者、受众、版本、TTL 和权限的最小冻结输入。 |
| Context Patch | 上下文变更提案 | 任务后的候选更新，未经用户批准不能写回。 |
| Session Contract | 会话契约 | 访谈前对目标、来源、范围、回合、时长和保存边界的约定。 |
| History-assisted | 历史辅助取证 | 授权后按当前目的读取必要历史，不是读取全部 Memory。 |
| Harness Memory | Agent 运行记忆 | Agent 平台维护的项目地图、偏好和历史摘要。 |
| Principal / Audience | 实际执行者 / 允许接收者 | 谁使用 Context，以及谁可以看到结果。 |
| Purpose-bound | 用途绑定 | Context 只允许用于明确声明并获批准的目的。 |
| Disclosure / Sensitivity | 披露规则 / 敏感级别 | “允许给谁、为何使用”和“内容有多敏感”是两个独立判断。 |
| TTL | 有效期 | View 到期后失效。1.0 默认 TTL 为 7 天。 |
| Canonical source | 唯一事实源 / 正式编辑源 | 副本冲突时被视为正式版本的来源。 |
| Single-writer | 单写入者 | 多个 Agent 可以提 Patch，但只有一个入口正式修改 Store。 |
| Fail closed | 失败关闭 | 条件不明确时拒绝继续，不猜测放行。 |
