# Brief Yourself Glossary

[中文](GLOSSARY.md) | [English](GLOSSARY.en.md) | [Governance](GOVERNANCE.en.md)

| Term | Chinese | Meaning |
|---|---|---|
| Personal Context | 个人上下文 | Personal information and calibrated understanding the user permits an agent to use under explicit conditions. |
| Personal Context Store | 个人上下文存储 | The user-reviewable long-term source of truth; not Agent Memory. |
| Claim | 认识条目 / 可审核陈述 | A personal statement with provenance, scope, status, counterevidence, and sensitivity. |
| Evidence / Counterevidence | 证据 / 反例 | Sources that support or limit a Claim. History starts as Evidence. |
| Tension / Unknown | 张力 / 未知项 | An unresolved pull or a question the available material cannot answer. |
| Core Summary | 核心摘要 | A derived summary of confirmed, active, cross-context Claims; not a second source of truth. |
| Domain | 领域标签 | A Claim tag such as career, expression, or collaboration; not a storage layer. |
| Context View | 上下文视图 / 冻结任务视图 | A minimum frozen input bound to purpose, principal, audience, revision, TTL, and permissions. |
| Context Patch | 上下文变更提案 | A proposed update after a task; it cannot be written back without user approval. |
| Session Contract | 会话契约 | The pre-interview agreement on goal, sources, scope, turns, duration, and storage. |
| History-assisted | 历史辅助取证 | Purpose-limited retrieval from authorized history, not a read of all Memory. |
| Harness Memory | Agent 运行记忆 | Project maps, preferences, and history summaries maintained by an agent platform. |
| Principal / Audience | 实际执行者 / 允许接收者 | Who uses the Context and who may receive it or its output. |
| Purpose-bound | 用途绑定 | Context is authorized only for a declared and approved purpose. |
| Disclosure / Sensitivity | 披露规则 / 敏感级别 | “Who may receive it and why” is separate from “how sensitive it is.” |
| TTL | 有效期 | The expiry period of a View. The 1.0 default is seven days. |
| Canonical source | 唯一事实源 / 正式编辑源 | The authoritative source when copies conflict. |
| Single-writer | 单写入者 | Multiple agents may propose Patches, but one controlled entry point modifies the Store. |
| Fail closed | 失败关闭 | Reject access when required conditions are unclear instead of guessing. |
